1. Navigate to the root directory of the project and rename .env-fill to .env
2. open the .env file
3. fill in the variables with your desired values.
	a. Put the desired value right nest to the equal sign without any space.
	b. Make sure that BACKEND_PORT and VITE_BACKEND_PORT are the same.
	c. Make sure that FRONTEND_PORT and VITE_FRONTEND_PORT are the same.
4. Fill in your Google Gemini API key.
	a. Keys can be managed at: `https://aistudio.google.com`
